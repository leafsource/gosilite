# 中后台高频任务设计

中后台产品业务不同，但高频任务高度同质。整体框架与页面布局明确后，按下表选任务流程再编码。

## 任务总览

| 任务 | A | B | 其他场景 |
|------|---|---|----------|
| 数据筛选与查询 | 查询后生效 | 立即生效 | 折叠条件；条件模版保存与调用 |
| 表格批量操作 | 所见即所得 | 选择后触发 | — |
| 效果预览 | 异步触发 | 同步预览 | — |
| 新手指引 | 阻断式指引 | 非阻断式引导 | 主动触发引导 |
| 数据导入 | 逐个文件导入 | 批量文件导入 | — |
| 状态流转 | 通过详情流转 | 通过列表摘要流转 | — |
| 任务引导 | 任务开始前引导 | 任务结束后引导 | — |

---

## 1. 数据筛选与查询

按条件选择数据项或查询结果。常用于仪表盘、列表页。

### A 查询后生效

- **何时**：查询范围明确，需一组条件一次提交。
- **核心流程**：选择条件 → 触发查询 → 获得结果 → 清空条件
- **组件**：时间/日期选择器、输入框、选择器、按钮、表格
- **本项目**：`s-table` 关键字 + `searchFields`，点「查询」才发 `search` 事件。

### B 立即生效

- **何时**：范围随机，需反复改条件，实时刷新。
- **核心流程**：条件选择 → 结果更新 → 条件修改 → 结果更新
- **组件**：同上；控件 `@change` 即查询。

### 折叠条件

- **何时**：筛选项过多，只展示高频，其余折叠。
- **流程**：展开条件 → 条件选择 → 获得结果
- **形态**：默认一行常用 +「更多条件」展开/收起。

### 条件模版保存与调用

- **何时**：筛选个性化强，需自定义保存。
- **流程**：条件选择 → 保存为模版（命名/可见性）→ 模版调用
- **形态**：筛选区「保存筛选器」+ 模版下拉（最近使用/我的模版）。

---

## 2. 表格批量操作

对报表多项数据统一操作。常用于列表页。

### A 所见即所得

- **何时**：批量为主或高频操作。
- **流程**：选择内容 → 操作 → 显示结果
- **形态**：批量按钮常显；未选中时 `disabled`；选中显示「已选 N 项」。
- **组件**：表格、按钮、多选框、下拉、全局提示。

### B 选择后触发

- **何时**：已有主按钮，批量为次级/低频。
- **流程**：选择内容 → 操作区出现 → 操作 → 结果
- **形态**：勾选后底部/顶部出现批量条。
- **组件**：下拉、多选、按钮、表格等。

---

## 3. 效果预览

编辑/变更未最终生效前，提前展示效果。用于仪表盘、结果页、详情页。

### A 异步触发

- **何时**：配置项多，或实时刷新有延迟，需集中预览。
- **流程**：填写表单/配置 → 点击预览 → 进行预览
- **形态**：页面级「预览」按钮；结果区异步加载。
- **组件**：表单、按钮、输入、上传、单/多选、选择器。

### B 同步预览

- **何时**：配置过程中需实时关注最终效果。
- **流程**：填写/设置 → 局部预览
- **形态**：左右分栏或卡片局部，随输入更新。

---

## 4. 新手指引

新用户功能介绍或使用说明，任意页面常见。

### A 阻断式指引

- **何时**：必读，或指引中不建议其他操作，需聚焦。
- **流程**：触发引导 → 逐步查看 → 结束
- **组件**：对话框（模态，挡住背景）。

### B 非阻断式引导

- **何时**：辅助说明，可边操作边看。
- **流程**：触发 → 查看或忽视继续操作 → 结束
- **组件**：气泡确认框、弹出层、文字提示。

### 主动触发引导

- **何时**：内容多、需反复查看。
- **流程**：触发入口 → 选择任务 → 进入引导 → 逐步查看 → 结束
- **形态**：浮动「一站式指引」入口 + 任务列表（引导中心）。

---

## 5. 数据导入

本地数据导入系统。常用于列表页。

### A 逐个文件导入

- **何时**：轻量快速导入，格式集中。
- **流程**：触发导入 → 选一个文件 → 开始导入 → 收到结果
- **组件**：按钮、上传、全局提示、表格/列表。

### B 批量文件导入

- **何时**：数据复杂或多文件。
- **流程**：触发导入 → 选择上传方式 → 批量上传 → 确认上传结果 → 导入
- **形态**：对话框上传列表（文件名/大小/状态）→「开始导入」→ 结果表（成功/失败标记）。
- **组件**：按钮、上传、全局提示、表格、对话框。

---

## 6. 状态流转

对单条数据调整状态。用于列表页、详情页、结果页。

### A 通过详情流转

- **何时**：信息多/复杂，需看详情再决策。
- **流程**：列表选定 → 查看详情 → 选择目标状态 → 确定 → 显示结果（可含流转记录）
- **组件**：步骤条、表格、表单、下拉、按钮。

### B 通过列表摘要流转

- **何时**：摘要即可决策，无需进详情。
- **流程**：列表选定 → 选择状态 → 显示结果
- **形态**：行内下拉/菜单（通过、驳回、挂起…）。

---

## 7. 任务引导

完成任务或使用功能时的必要指导。用于详情页、结果页。

### A 任务开始前

- **何时**：任务复杂或开始前需准备。
- **流程**：查看引导 → 按引导执行
- **形态**：步骤条总览 + 资料清单提示 + 主操作按钮。

### B 任务结束后

- **何时**：结果关联下一任务，或完成后触发其他操作。
- **流程**：执行任务 → 查看结果引导 → 是否执行下一任务
- **形态**：成功态 + 后续任务卡片（去完成 / 下次再说）。

---

## 与 s-table / 本项目对齐

| 需求 | 落地 |
|------|------|
| 查询后生效 | `s-table` 默认：查询/重置按钮 |
| 立即生效 | `searchFields` 选项 `@change` 触发 search（扩展） |
| 折叠条件 | `searchFields` 拆常用/全部 + 展开收起（扩展） |
| 批量 A/B | `selection-change` + toolbar 或底部条 |
| 状态列表流转 | 行内 `t-dropdown` + `t-tag` |
| 详情流转 | 详情页 `t-steps` + 审批表单 |

扩展 `s-table` 新能力时保持 props/events 向后兼容，并先用 TDesign MCP 查相关组件。
