---

gosilite 是 Agent 驱动的轻量级 Go + Vue3 全栈快速开发框架：后端唯一 CloudWeGo Hertz，前端 Vue3 + TypeScript + Vite + TDesign。

本站由 **Hugo 生成静态文件**，**Hertz 托管**在 `/docs/` 路径下——文档基建本身就是一次 Hugo × Hertz 集成实践（原理见[参考](/docs/reference/)）。首次运行请从[快速开始](/docs/quick-start/)开始；准备发布时阅读[发布 v0.1.0](/docs/release/)。
